Sapiens

Sapiens est un jeu de simulation préhistorique sorti sur Thomson MO5 en 1986, puis décliné sur Mac OS classique en 1996. Il y a cent mille ans, la tribu des Pieds-Légers est affamée : vous incarnez Torgan, un jeune guerrier envoyé explorer des territoires inconnus pour trouver de quoi nourrir les siens et survivre dans un monde hostile. Le jeu se déroule en vue subjective et se pilote à la souris.

Portage en Rust (WebAssembly) de la version Mac OS passée en open source en 2017, distribuée sous licence GNU GPL v3. Page originale : myriad-online.com. Code source du portage : github.com/kpouer/Sapiens.
